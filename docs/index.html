🔌 Learn MCP the school way

The Model Context Protocol — the standard plug between AI apps and the world — taught with a difference: the protocol is IN the repo. A real MCP server and a real host/client, ~200 lines of pure Python, zero dependencies. You read every byte that moves.

  • three shelves; three verbs and a handshake 🤝

🔧 Part 2 — BUILD & DEPLOY (6–8)

git clone https://github.com/BaluRaut/learn-mcp-school.git && cd learn-mcp-school
python3 client/mini_client.py          # watch every JSON-RPC message
python3 client/mini_client.py --drive  # YOU pick the tool calls
