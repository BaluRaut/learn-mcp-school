🔌 MCP शाळेच्या पद्धतीने शिका

Model Context Protocol — AI ॲप्स आणि जग यांच्यामधला प्रमाणित प्लग — एका फरकाने शिकवलेला: प्रोटोकॉल रेपोच्या आतच आहे. खरा MCP server आणि खरा host/client, शुद्ध Python च्या ~230 ओळी, शून्य dependencies, सध्याची प्रोटोकॉल आवृत्ती (2026-07-28) बोलणारा. हलणारा प्रत्येक byte तुम्ही वाचता.

  • adapter चा ड्रॉवर 🍝 → मानक socket 🔌

  • stdio विरुद्ध Streamable HTTP + तीन विश्वासाची धोरणे 🚧

🧭 Cheat sheet — उपमा, कोण ठरवते, तीन धोरणे
